# Tempest

## Overview

Tempest is the first capstone challenge in the SOC Level 1 path, tying together every skill built across the previous rooms into a single end-to-end incident response investigation. Acting as an Incident Responder handling a CRITICAL-severity alert, the room walks through reconstructing a complete attack chain from a malicious phishing document through Initial Access, Execution, Discovery, Lateral Movement, Privilege Escalation, and Persistence, using Sysmon logs, Windows Event Logs, and a packet capture, with EvtxECmd, Timeline Explorer, SysmonView, Wireshark, and Brim as the primary analysis toolset.

## Task 2 - Log Analysis and Event Correlation

Reviewed the two foundational concepts underpinning the investigation: Log Analysis (understanding events generated by a system to identify anomalies) and Event Correlation (connecting related artefacts across multiple log sources, such as linking a Sysmon network connection event to a firewall log via shared fields like source/destination IP, port, process name, and user account) to build a complete picture of an incident.

## Full Attack Chain

1. **Initial Access** - Phishing document (free_magicules.doc) exploiting CVE-2022-30190 (Follina) via MSDT
2. **Execution** - Base64-encoded PowerShell payload writes update.zip to the Startup folder for persistence
3. **Stage 2 Download** - On next login, certutil.exe downloads first.exe from phishteam.xyz
4. **C2 Establishment** - first.exe (Nim-compiled) connects to resolvecyber.xyz:80, using base64-encoded GET requests with a q parameter
5. **Internal Reconnaissance** - Attacker discovers a sensitive file containing a password (infernotempest) and enumerates listening ports
6. **Lateral Movement** - Chisel (ch.exe) establishes a reverse SOCKS proxy to 167.71.199.191:8080, enabling WinRM authentication
7. **Privilege Escalation** - PrintSpoofer (spf.exe) abuses SeImpersonatePrivilege to gain SYSTEM, launching final.exe for a second C2 channel on port 8080
8. **Persistence** - Two backdoor accounts created (shion, shuna), shion added to local Administrators, and a malicious service (TempestUpdate2) configured to auto-start final.exe on every boot

## Key Takeaways

- This capstone room demonstrates why event correlation matters more than any single log source. No individual artefact (Sysmon alone, the packet capture alone, or Windows Event Logs alone) tells the full story; only combining process creation, DNS queries, network connections, and account management events across all three sources reconstructs the complete eight-stage attack chain.
- CVE-2022-30190 (Follina) is a striking example of a zero-click, macro-free Office exploit, and tracing WinWord.exe spawning msdt.exe with a base64-encoded payload is a textbook parent-child process anomaly worth recognizing in any Word-based intrusion.
- The attacker's toolchain relied heavily on legitimate, dual-use software (certutil.exe for downloading, Chisel for tunneling, PrintSpoofer for privilege escalation) rather than obviously malicious custom malware, reinforcing a theme across the whole SOC Level 1 path: attackers prefer tools that blend into normal administrative activity over anything that would trigger simple signature-based detection.
- SHA256 hash lookups were the fastest path to identifying otherwise-unlabeled tools (Chisel, PrintSpoofer) throughout this investigation, underscoring why maintaining and querying known-hash databases is such high-value SOC tradecraft.
- The persistence stage (backdoor accounts, group membership changes, and a malicious auto-start service) directly mirrors the exact techniques covered in the Windows Threat Detection series, demonstrating how foundational detection knowledge scales up into a full incident response narrative when applied end-to-end against a real artefact set.
